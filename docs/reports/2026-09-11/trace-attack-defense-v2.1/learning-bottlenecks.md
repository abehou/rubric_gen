failures; User has 129, 136 and 10 respectively. Thus the remaining User
funnel loss is concentrated more in native support/margin protection and
undecidable applications than in sidecar creation or source binding. The guard
was mechanical and did not change these counts for completed assignments.

The observed Full gap changes are W−S −1.58 and W−A −4.57 with ΔS +0.70 and
ΔA +3.69. User W−A improves only −0.78 while W−S worsens +1.85 because W rises
1.23 and S falls 0.62 despite ΔA +2.01. This supports a narrow interpretation:
the candidate's gap behavior is not a uniform calibration improvement, and the
User bottleneck is strong-score retention. Rule exposure is observed delivery,
not proof of compliance or RH causation.
