# Research reports

Dated reports outside that checkpoint are internal historical development/provenance records. Their version labels do not define current paper conditions. Detailed diagnostic JSON payloads and raw traces are local-only, with paths, SHA256 and sizes in [the evidence manifest](../archive/baseline-freeze-20260909/local-evidence-manifest.json). A GitHub clone contains code, configurations, compact reports and receipts; it does not contain the benchmark data or experiment workspaces. No historical raw evidence was deleted.
