## Minimum-stage decision

| Proposed change | Necessary rerun | Reuse when native provenance/compatibility passes |
|---|---|---|
| Final-artifact audit prompt, routing, threshold or audit code | Final-artifact audit only | Frozen final artifacts; all revision work, trajectories, other audits and unchanged scores |
| Trajectory detector logic/prompt | Only affected trajectory audit windows | Existing frozen trajectories and artifacts; revisions and unrelated audits/scores |
| Simulator feedback, dynamic generation/admission/delivery, solver behavior | Affected revision conditions and downstream artifact-dependent evaluations | Shared seeds/paraphrases; compatible starting rubrics and unchanged controls; unchanged judgments only for identical bound inputs/configuration |
| Reporting/aggregation presentation | Local or allocated analysis as appropriate | All scientific provider outputs; no provider calls |

Reuse is conditional on exact input content, model/settings, prompt/code identity and native acceptance; never copy judgments to changed inputs, patch historical hashes, overwrite outputs or fabricate compatibility. Version new audit outputs and keep original audit control. Reuse is not a reason to weaken validation.

## Auditor calibration gate

Before selecting any replacement auditor prompt or threshold, construct a condition-blinded human-reviewed calibration set with positive and negative cases. Remove condition identifiers from review packets and keep a separate protected mapping; include ambiguous cases and record adjudication/uncertainty. A model's label is not human review. Do not claim calibration is complete without actual human-reviewed labels.

Separate calibration/development cases from held-out validation cases, preferably by task to limit leakage. Prespecify candidate selection using sensitivity, specificity, abstention and auditor agreement, with uncertainty and error examples. Do not select against static > trace ordering or inspect condition-specific rates to tune the detector. Freeze selected prompt/threshold/model/settings and packet hashes before uniformly applying it to every existing condition. Preserve original results and publish the audit-version sensitivity comparison. A changed measurement is not a behavioral mitigation result.

If suitable human-reviewed labels are absent, prepare a blinded review packet and continue policy analysis with frozen evaluators; request human adjudication when required, without blocking independent work or substituting AI labels.
