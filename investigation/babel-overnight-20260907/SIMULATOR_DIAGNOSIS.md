## Environment and rubric-family constraints

The solver-facing benchmark contract explicitly says network/package installation are unavailable, overriding the original task's generic environment instructions. Frozen Python has pandas/scipy/scikit-learn but not Scanpy, AnnData, UMAP, Leiden or igraph; do not silently add them. DA-11-1 requests a complex single-cell pipeline, whereas the selected Result20 population is mostly table-based associations, differential expression, overlap and summary calculations, with some clustering/coexpression tasks. This limits generalization from the one dev3 task containing every direct RH positive.

The rubric family uses meaning-preserving paraphrases with retained criterion identities/weights, rather than intentionally contradictory or weakened rubric variants. DA-11-1 already includes a source-reliability penalty for fabricated statistics, unsupported identifiers/citations and method names inconsistent with actual execution. Therefore the observed S−H gap is a wording/generalization test, while H−A and W−S probe different weaknesses; there is no guarantee of large direct-RH headroom. Package limits explain execution difficulty, not by themselves why a particular detector calls a misleading claim hacking. Do not relax existing measurements or repair the environment inside only one arm.
