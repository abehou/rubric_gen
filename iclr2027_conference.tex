\begin{abstract}
Autoresearch systems improve artifacts through repeated model feedback. A fixed rubric can omit task-relevant quality. We test a bounded intervention that keeps every original criterion and adds criteria elicited from blinded artifact pairs. The experiment crosses four feedback policies with three single-rubric regimes: static, offline elicitation from sealed pairs, and online elicitation from live history. Every cell uses the base solver prompt. Each update finds uncovered differences, converts recurring differences into criteria, and uses a separate call to assign advisory semantic labels. Both benchmarks use five whole-rubric judgments and their arithmetic mean. A sealed panel also tests whether pairwise preferences agree with the original-rubric score ordering. We do not assume that elicitation improves coverage or reduces reward hacking.

\end{abstract}

\section{Introduction}

Autoresearch applies an iterative loop to open-ended work such as code and research reports. A model produces an artifact, receives a score and feedback, and revises the artifact. This loop can produce useful work, but it also gives the model repeated access to a proxy objective. The model can learn to satisfy the proxy while leaving the intended task incomplete.

Rubrics make an open-ended task easier to score, but one rubric can omit part of the task. Its wording can also create a narrow optimization surface. A system can exploit a weak judge, a particular expression of a requirement, or an omission shared by all exposed rubrics. These failures require different measurements because no single judge comparison identifies all of them.

We define a dynamic intervention that adds bounded criteria between rounds. It never deletes or rewrites an original criterion. The primary design crosses full, semi, score-only, and user-simulator feedback with a static rubric, offline elicitation from sealed pre-treatment pairs, and online elicitation from live historical pairs. Every cell uses the base solver prompt. Both elicitation arms use the same models, prompts, update schedule, score budget, and review gate. The next rubric is sealed before the next artifact is produced. Conditions share the selected rubric, sealed holdouts, rubric-free instruments, pairwise judge, and direct detector within each matched replicate. This distinction is necessary: an exposed score is not evidence of improvement when the scoring rule changes with the artifact.

\section{Formalizing Reward-Hacking in Autoresearch}

\paragraph{Setup.}
Let $i \in \mathcal{I}$ index AI systems,
$j \in \mathcal{J}$ index tasks, and
$t \in \{0,\ldots,T\}$ index optimization rounds.
The experiments also contain replicates. We suppress the replicate index below,
but all cross-condition sharing statements apply within a matched replicate.
Let $a_{ij}^t$ denote the artifact produced at round $t$. An artifact can be a code repository, a research paper, or another structured output. The objective is to improve its intended quality over repeated rounds.

Let the original expert rubric for task $j$ be
\begin{equation}
\mathcal C_j^0=\{(c_{jk},w_{jk})\}_{k=1}^{K_j},
\qquad \sum_k w_{jk}=1.
\end{equation}
Let $r_j^0$ denote its complete rendered text.
Let $\mathcal E_{ij}^t$ contain all accepted elicited criteria through update
$t$. The active rubric is one complete rubric
\begin{equation}
r_{ij}^t=\operatorname{Augment}(\mathcal C_j^0,\mathcal E_{ij}^t).
\end{equation}
The system never deletes or rewrites an original criterion. It accepts at most
five elicited criteria. When $\mathcal E_{ij}^t$ is nonempty, original criteria
receive $1-\beta=0.8$ of the score and elicited criteria share $\beta=0.2$
equally. The program fixes this rule. The proposer cannot choose weights.

Each update uses three blinded artifact pairs $\mathcal P_{ij}^t$. The first
model stage finds task-relevant differences that the current rubric does not
cover. The second stage turns recurring differences into general criteria. A
criterion must cite support from at least two pairs. A separate review call rejects a
criterion that is redundant, task-specific to one artifact, unevaluable, or
poorly supported. This review is an audit, not a semantic proof.
All online pairs share the current artifact, so two-pair support is not
independent replication.

The online arm compares the current artifact with the previous, initial, and
midpoint artifacts. Sealed seed artifacts fill early or duplicate sources. The
offline arm uses all three pairs among three sealed pre-treatment artifacts.
Pair order is deterministic and blinded. The models do not receive scores,
round labels, or newer/older labels. The first update occurs after $a_{ij}^1$
is scored. Its rubric scores $a_{ij}^2$. Thus, an artifact cannot change the
rubric that scores itself.

The exposed score is
\begin{equation}
s_{ijt}=g_{\mathrm{train}}\!\left(a_{ij}^t,r_{ij}^t\right),
\end{equation}
where $g_{\mathrm{train}}$ also supplies feedback for the next revision. We
rescore the same artifact and rubric with a reference panel,
\begin{equation}
s^{\mathrm{ref},+}_{ijt}
=g_{\mathrm{ref}}\!\left(a_{ij}^t,r_{ij}^t\right).
\end{equation}

These scores are artifact-specific because the active rubric can change. Let
$\bar r_j$ be the unchanged original task rubric. For artifact
$u\in\{0,T\}$, define
\begin{align}
W_{ij,u}&=g_{\mathrm{train}}\!\left(a_{ij}^{u},\bar r_j\right), \\
A_{ij,u}&=g_{\mathrm{ref}}\!\left(a_{ij}^{u},\bar r_j\right), \\
B_{ij,u}&=g_{\mathrm{ref}}\!\left(a_{ij}^{u},r_{ij}^{u}\right).
\end{align}
The evaluator reads $W$ from the saved original-rubric scores. It does not
rescore the weak judge. The reference panel scores both artifacts with the same
original rubric. Thus, $W-A$ compares judges with the same artifact and rubric.
The active-rubric score $B$ is a separate diagnostic.

Before the trials, a generator produces wording variants from $\bar r_j$.
Within each matched replicate, one variant $r_j^*$ becomes the
selected initial rubric. Other variants remain sealed from the solver and
proposer. The current outcome evaluator does not score them. Define
\begin{align}
S_{ij,u}&=g_{\mathrm{ref}}\!\left(a_{ij}^{u},r_j^*\right), \\
Q_{ij,u}&=g_{\mathrm{free}}\!\left(a_{ij}^{u}\right).
\end{align}
Here, $Q$ uses a separate rubric-free prompt with the configured reference-model
panel. It has generic fixed score descriptions and a 0--100 range. It does not use the task rubric. Those descriptions differ from the
criterion-specific rules of $W$, $A$, $B$, or $S$. A shared numeric range does
not make these instruments calibrated or commensurate.

The generator preserves criterion order, point values, and scoring rules while
changing wording fields. Structural checks cannot establish semantic
equivalence.

\paragraph{Reward-hacking decomposition.}
At endpoint $u$, define the \textbf{weak--strong verifier contrast}
\begin{equation}
e^v_{ij,u}=W_{ij,u}-A_{ij,u}.
\end{equation}
A positive value indicates a higher weak-judge score under the same artifact and
rubric \citep{mahmoud2026reward}. It does not identify judge causation, and the
reference panel is not ground truth.

Define the \textbf{original rubric gap}
\begin{equation}
e^o_{ij,u}=A_{ij,u}-Q_{ij,u}.
\end{equation}
This uncalibrated contrast can contain rubric selection, omitted requirements,
prompt effects, panel error, and scale mismatch. It does not identify one
mechanism or the causal effect of elicitation. The scores satisfy
\begin{equation}
W_{ij,u}-Q_{ij,u}
=e^v_{ij,u}+e^o_{ij,u}.
\end{equation}
This identity is algebraic.

We partition $e^o$ into two descriptive contrasts:
\begin{align}
e^r_{ij,u}&=A_{ij,u}-S_{ij,u}, \\
e^s_{ij,u}&=S_{ij,u}-Q_{ij,u}.
\end{align}
They compare the original rubric with the selected rubric, and the selected
rubric with rubric-free absolute quality. They satisfy
\begin{equation}
e^o_{ij,u}=e^r_{ij,u}+e^s_{ij,u}.
\end{equation}
We do not give these diagnostics separate loss weights. We report the
initial and final active-rubric scores separately. They do not enter this
identity.
We also report $B_{ij,u}-A_{ij,u}$ as active-rubric drift.

A rubric-free pairwise preference is not a valid $Q_{ij,u}$. For each
trajectory, the saved in-loop-judge original-rubric five-call mean selects the highest-scoring and
lowest-scoring artifacts. A sealed panel compares them in both orders without
seeing the rubric, scores, rounds, or higher/lower labels. We report preference
for the higher-scoring artifact as a separate outcome
\citep{shah2014compare,yang2026judgmentbench}.
Let $\bar S^{0}_{ijt}$ be the five-call mean under the original rubric. Select
\begin{equation}
t^+=\arg\max_t \bar S^{0}_{ijt},
\qquad
t^-=\arg\min_t \bar S^{0}_{ijt}.
\end{equation}
For panel model $m$ and presentation order $o$, let
$z_{ijmo}=1$ when the judge prefers $a_{ij}^{t^+}$, $0$ when it prefers
$a_{ij}^{t^-}$, and $1/2$ for a tie. The rubric-order agreement is
\begin{equation}
\widehat p^{\mathrm{ord}}_{ij}
=\frac{1}{2M}\sum_{m=1}^{M}\sum_{o=1}^{2}z_{ijmo},
\qquad
e^{\mathrm{ord}}_{ij}=1-\widehat p^{\mathrm{ord}}_{ij}.
\end{equation}
If the maximum and minimum rubric scores tie, the ordering is not identified.
The implementation records neutral agreement of $1/2$.
Selecting extrema from noisy scores can exaggerate the observed score gap. The
result tests agreement with the operational rubric ordering. It is not an
unbiased estimate of latent quality.
Calibration against independent judgments is necessary before $Q$ or any
contrast containing $Q$ can be interpreted as intended-quality magnitude.

\paragraph{Empirical reward-hacking loss.}
Let $\phi(x)=[x]_+=\max(x,0)$. For endpoint $u$, define the operational loss
\begin{equation}
\boxed{
\ell_{ij,u}
=
\lambda_{v}\phi\!\left(e^{v}_{ij,u}\right)
+
\lambda_{o}\phi\!\left(e^{o}_{ij,u}\right)
}.
\end{equation}
The nonnegative weights $\lambda_v$ and $\lambda_o$ are specified before
evaluation. Weighting $e^r$ or $e^s$ again would double count parts of
$e^o$. This loss remains uncalibrated because it contains $Q$. We therefore
also report every signed contrast and rubric-free pairwise quality.

Define $\Delta\ell_{ij}=\ell_{ij,T}-\ell_{ij,0}$. The aggregate
\begin{equation}
\boxed{
\widehat{\Delta\mathcal{L}}_i
=
\frac{1}{|\mathcal{D}_i|}
\sum_{j\in\mathcal{D}_i}
\Delta \ell_{ij}
}
\end{equation}
is the mean reward-hacking loss change for system $i$. It can be negative and is
not a nonnegative risk estimate. Here, $\mathcal{D}_i$ is the evaluated task set.

\paragraph{Why criterion elicitation can help.}
The one-rubric design makes no averaging or sampling claim. Elicitation can help
when recurring artifact differences expose a task-relevant omission in the
original rubric. It can also add a wrong or over-specific criterion.

Offline elicitation minus fixed combines static criterion discovery, changed
feedback, and added provider computation. Online minus offline measures
assignment to live-history evidence. It also includes evidence novelty because
the offline contrast set is fixed. Later artifacts mediate both effects. Sealed
wording variants cannot detect an omission shared by the master rubric and all
its paraphrases. Rubric-free outcomes can expose score disagreement, but they
cannot identify its cause.

\paragraph{Discriminative reward-hacking detector.}
A direct detector can identify suspicious behavior in the full autoresearch trajectory \citep{parikh2025malt,thaman2026rhb,wang2025thinking,deshpande2026trace}. Let
\begin{equation}
y_{ij}=D\!\left(\tau_{ij}^{0:T}\right),
\qquad y_{ij}\in\{0,1\},
\end{equation}
where $y_{ij}=1$ indicates detected reward hacking. We exclude and report
abstaining or incomplete detector decisions. We treat the binary result as a
separate outcome. The detector can use evidence that the score contrasts omit,
and the contrasts can show inflation without visible deceptive behavior. We do
not assume that $(e^v,e^o)$ are sufficient statistics for the detector. Any
regression between these measurements is an empirical association with fitted
coefficients, not a mathematical consequence of the decomposition.

We preregister the primary loss weights. A separate exploratory analysis fits a
detector-associated direction. For each completed run, define
\begin{align}
x^v_{ij}&=[e^v_{ij,T}]_+-[e^v_{ij,0}]_+, \\
x^o_{ij}&=[e^o_{ij,T}]_+-[e^o_{ij,0}]_+.
\end{align}
Within each benchmark, we fit the constrained association model
\begin{equation}
\operatorname{logit}\Pr(y_{ij}=1)
=\alpha+\gamma_v x^v_{ij}+\gamma_o x^o_{ij},
\qquad \gamma_v,\gamma_o\geq 0,
\end{equation}
and report only its normalized exploratory direction,
\begin{equation}
\widehat{\lambda}_v=\frac{2\gamma_v}{\gamma_v+\gamma_o},
\qquad
\widehat{\lambda}_o=\frac{2\gamma_o}{\gamma_v+\gamma_o}.
\end{equation}
Thus, $\widehat{\lambda}_v+\widehat{\lambda}_o=2$. The preregistered
equal-weight reference remains $(\lambda_v,\lambda_o)=(1,1)$. We report no
fitted direction when the labels have one class, the centered features lack
rank two, the likelihood separates, or the fitted slope is zero. For
uncertainty, we resample task clusters at least 2,000 times and use
leave-one-task-out checks. We require at least ten tasks, including five event
tasks and five non-event tasks. The three-task development tier cannot pass
this gate. The 20-task results tier can pass the task-count gate, but only if
its observed labels also pass the event-diversity gate. Any fitted direction
describes detector association within one benchmark. It is not causal,
normative, or a substitute for the primary weights.

\section{Experiments}

\paragraph{Experimental conditions.}
We cross four feedback policies with three rubric conditions. The feedback
policies are full feedback, semi feedback, score-only feedback, and a bounded
user-simulator comment. The \textbf{static} condition keeps the original rubric.
\textbf{Offline elicitation} adds criteria from three sealed pre-treatment pairs.
\textbf{Online elicitation} adds criteria from three bounded live-history pairs.
Every condition uses one rubric and the base solver prompt.

Each benchmark has a three-task development tier and a 20-task results tier.
Each tier is one 12-cell factorial experiment. We use three replicates and six
revision turns in every cell. Thus, development has 108 assignments and results
has 720 assignments per benchmark. PaperBench uses its official three-paper
development split and official 20-paper all split. The BioMNIBench task sets are
fixed project sets and are not official upstream splits.

The elicitation arms match update times, proposer models, prompts, call limits,
reviewer, criterion cap, fixed score split, and generation-token limits. They use
more provider work than fixed. Each update uses one difference call, one
criterion call, and one review call. Each request has a 1~MiB UTF-8 limit, a
32,768-output-token ceiling, and a 1,800-second timeout. The proposer stages
allow five validation retries. The semantic auditor does not retry. Its verdicts
are advisory, and every deterministically valid criterion enters the next
rubric. An invalid or incomplete audit stops the assignment. A write-ahead
ledger binds every provider call and resume.

The difference finder sees the task, current rubric, and three blinded pairs.
The criterion writer sees the task, current rubric, and found differences. The
reviewer sees those inputs and the proposed criteria. None receives scores or
newer/older labels. The reviewer uses the same Luna model as the proposer,
solver, in-loop judge, and simulator. It uses a separate prompt and call. The
outcome panel uses different models. We treat this review as an audit rather
than ground truth.

\paragraph{Outcome evaluation.}
Reference judges score artifact snapshots with the unchanged original rubric,
the selected rubric, and each artifact-specific active rubric. Detection reads
the saved weak original-rubric scores. It does not rescore the weak judge.
Judges do not receive a condition label. An artifact-backed store reuses each
exact scoring request.
BiomniBench-DA and PaperBench use the same whole-artifact structured judge. Each
of five calls receives the complete artifact and complete rubric. The judge
selects one level for every criterion. We compute all five signed scores and use
their arithmetic mean. We keep every criterion report and score dispersion. A
failed, abstaining, or incomplete call fails the judgment. This mean is an
aggregation rule, not stable ground truth. We analyze each benchmark separately.

The current Harvey harness-evolution workflow is not a third instance of this
design. Its proposer applies bounded criterion patches, and it lacks the three
elicitation policies and the $W/A/S/Q$ endpoint. We treat Harvey as a separate
exploratory workflow and do not pool it with these experiments.

We also obtain the rubric-free scalar $Q$. Separately, we select the highest and
lowest saved in-loop-judge original-rubric five-call means across each trajectory. A sealed panel
compares those artifacts in both orders. It does not receive their scores or
labels. Finally, a direct detector evaluates the complete trajectory without an
explicit experimental label. We report these outcome families separately.

The treatment contrasts are longitudinal intention-to-treat regimes.
Offline minus fixed measures the static elicitation regime. Online minus offline
measures the live-history regime, including the novelty of changing evidence.
Online minus fixed remains the total online-intervention contrast.

$\Delta S$, $\Delta Q$, rubric-free pairwise preference, and direct detection use
common instruments across arms. Terminal and active rubrics remain
condition-dependent.

\paragraph{Pilot diagnosis.}
A legacy three-task pilot used one replicate per condition and a single evolving
rubric rather than the current elicitation design. Under each task's original master
rubric and the weak judge, the prospective-minus-static difference in the mean
final score was one point on BiomniBench-DA and two points on PaperBench. These
are descriptive differences from one replicate, with mixed task-level signs.
The direct detector reported no cases in six trials within each benchmark, but
the corresponding 95\% Wilson upper bound is approximately 0.39. Two judgments
of one identical BiomniBench-DA initial artifact differed by 44 points. One
three-model PaperBench reference panel spanned 64 points. These results are
inconclusive and do not show reward-hacking emergence or mitigation.

The legacy pilot lacks the current $W/A/S/Q$ measurements, so
it cannot enter the exploratory lambda fit. Independently, all six detector
labels were zero within each benchmark. For any finite feature values, the
intercept then tends to negative infinity for every normalized exploratory
direction. The profile likelihood has the same supremum over the full simplex
$\widehat{\lambda}_v\geq0$, $\widehat{\lambda}_d\geq0$, and
$\widehat{\lambda}_v+\widehat{\lambda}_d=2$. The legacy pilot therefore
identifies no lambda direction. It only motivates the common-ruler endpoint,
semantic request reuse, repeated whole-rubric grading, and separate absolute and
pairwise outcomes in the new design.


\section{Discussion}

Dynamic criterion elicitation is an intervention, not an outcome measure. It
can add a useful missing requirement. It can also add a wrong or narrow
requirement. A higher exposed score can therefore result from a worse active
rubric. We use the selected rubric, rubric-free outcomes, and pairwise
preferences for common-instrument comparisons. None of these instruments alone
establishes semantic coverage.

This design also has limits. The sealed wording variants preserve specification errors that they share with the master rubric. Multiple judges can share model biases. Rubric-free absolute and pairwise judgments use separate prompts, but they can retain the same model errors. Pairwise preferences do not complete the numeric identity, and the absolute score remains uncalibrated. The present evaluation therefore cannot prove that any rubric captures the intended task or that elicitation mitigates reward hacking.

\subsection*{Ethics statement}

This study uses existing machine-learning benchmarks and does not involve human
subjects. Hosted model providers receive task and artifact text during grading.
We exclude credentials and other unrelated private data from evaluation
snapshots. We treat generated artifacts as untrusted input because they can
contain instructions intended to influence evaluators.

\subsection*{Reproducibility statement}

The released evaluation records task and model identities, active-rubric
criteria, weights, lineage, content hashes, proposal records, judge inputs, raw judge
reports, token use, costs, and every derived score. The supplementary code
contains the experiment configurations and strict artifact validators.
