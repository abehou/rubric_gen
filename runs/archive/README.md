# Historical experiments and incident evidence

Organized on 2026-09-06. Each directory here was moved from the same name
directly under `runs/`: `studies`, `detections`, `preflights`, `quarantine`,
`reports`, and `logs`. `diagnostics/` contains old CPU/backup-check evidence
and disposable Python cache files formerly beside diagnostic scripts.

These are not all failed experiments. Older BioMNIBench/PaperBench results are
retained for historical reference, not mixed with the completed Results20
dataset. No raw record was edited and nothing here was permanently deleted.

Original absolute paths remain in records. This archive is for inspection;
production resume and old incident helpers are not asserted to work after
relocation. No compatibility metadata has been fabricated. Consult the dated
experiment log for original invocation paths and scientific context.

`logs/bounded_run.py` is historical only: the user requested ETAs, not hard
deadlines. Do not use this old launcher for new experiments.

Current results: [BioMNIBench red-team](../biomnibench-redteam-2026-09-05/README.md).
